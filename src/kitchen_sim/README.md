# kitchen_sim

A MoveIt Pro base configuration for the Franka arm.
For detailed documentation see: [MoveIt Pro Documentation](https://docs.picknik.ai/).

It is based on `fr3_solo_mock` from `src/external_dependencies/moveit_pro_franka_ws`, which supplies the SRDF, MoveIt parameters, Behavior loaders and gripper Objectives.
This package adds the MuJoCo scene, its own controllers, waypoints and Objectives.
